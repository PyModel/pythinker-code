# Glossary

- **Remote Control link**: The URL printed by `pythinker rc`. It grants control of the Mac. It does not contain the bearer token.
- **Envelope**: The JSON wrapper on every API response. `code` is the business result. `data` is the payload.
- **Snapshot**: The session rebuild payload. It carries the watermark used to subscribe again after a drop.
- **Approval**: A pending permission request for one tool call.
- **Question**: A pending structured ask with labeled options.
