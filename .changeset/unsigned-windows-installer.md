Windows: the installer is no longer code-signed. If you use Pythinker 1.7 or earlier on Windows, the in-app update fails for this version, so install it once by hand: download the `x64-Setup.exe` file from [the latest release](https://github.com/PyModel/pythinker-desktop-releases/releases/latest) and run it. Your settings and sessions stay. If Windows shows "Windows protected your PC", select **More info**, then **Run anyway**. After this, updates install in the app again.
