# Sign in or add a provider

Pythinker Code can talk to many model providers. Set up one of these:

- **Pythinker account** — select **Sign in** in the chat view. A browser window opens to complete the sign-in.
- **Your own API key** — open the settings menu in the chat view and add a provider from the catalog. Enter your API key for that provider.

You do this once. Pythinker stores the configuration and uses it for all later sessions.

To sign out later, run **Pythinker Code: Logout** from the Command Palette.
