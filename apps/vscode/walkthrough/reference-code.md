# Reference your code

Give Pythinker the exact files and lines you mean:

- Type `@` in the chat input to search the workspace and attach a file to your message.
- Put the cursor in an editor (or select some lines) and press `Alt+K`. Pythinker inserts a mention of that file into the chat input.
- A selection adds the line range to the mention, so Pythinker reads exactly the code you selected.

You can also right-click in an editor and select **Pythinker Code: Insert Current File**.
